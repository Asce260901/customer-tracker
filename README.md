# CRM Lite

A lightweight Customer Relationship Management (CRM) web app built with vanilla JavaScript and HTML. Designed to help small businesses track customers, log interactions, and manage basic sales workflows without needing a backend.

## Features

- Add and manage customer records
- Log customer interactions and notes
- Search and filter customer data
- Simple, no-framework interface using vanilla JS

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/Asce260901/crm-lite.git
```
2. Open `index.html` in your browser — no build step required.

## What I Learned

Building this project helped me understand how to manage state in a web application without a framework, structure modular JavaScript functions, and create a clean UI using only HTML and CSS. It also reinforced the importance of clean data handling and event-driven programming.
